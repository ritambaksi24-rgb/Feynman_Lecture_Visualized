# 28 — Content Authoring and Editorial Pipeline

Chapter production is an editorial and scientific workflow, not merely page implementation.

~~~text
Feynman Source
   ↓
Chapter Map
   ↓
Section Decomposition
   ↓
Idea Definitions
   ↓
Scientific Model
   ↓
Exploration Design
   ↓
Visualization Design
   ↓
Implementation
   ↓
Validation
   ↓
Publication Review
~~~

Each chapter records section order, conceptual flow, idea boundaries, dependencies, and learning intent.

Every idea is defined before UI implementation with source provenance, scientific references, linked models, exploration needs, and visualization needs.

Scientific review covers claims, equations, units, assumptions, approximations, numerical methods, and expected behavior.

Exploration review defines model, parameters, valid ranges, initial conditions, expected outputs, plots, reset, failure behavior, and accessibility.

Every external/generated asset has provenance/licensing metadata.

Meaningful editorial changes remain traceable to the Feynman source.

A chapter is publishable only after content, scientific, schema, accessibility, visual, performance, and rights/provenance review.

Changing explanatory content should not require changing renderer implementation.
